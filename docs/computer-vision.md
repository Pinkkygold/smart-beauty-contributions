# Computer vision experience

## Work described

My AI engineering responsibilities included work and research around facial skin-analysis workflows, image preprocessing, dataset preparation and annotation, YOLO-based detection, and deep-learning evaluation.

Technologies associated with this work included Python, PyTorch, TensorFlow, Keras, and YOLO. These describe my experience; this repository contains no executable model implementation or benchmark demonstrating proficiency in each tool.

## Workflow

Prepare data → inspect annotation quality → organize training and validation data → train or evaluate candidate models → review errors → consider application integration.

I considered how inference output would connect to a backend service and a user-facing application, in addition to model behavior in isolation.

## Boundaries

These responsibilities are self-reported from my internship context. The local web repository history does not independently verify model training or dataset work. I do not claim to have implemented all Smart Beauty analysis capabilities or provide unverified accuracy numbers.

Company datasets, images, labels, weights, notebooks, model configurations, and unpublished research results are omitted. No diagnostic or medical-performance claim is made.
